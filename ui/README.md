# VibeGo UI

VibeGo 的前端界面服务于一个目标：让用户可以从浏览器接回自己的开发环境，在手机、平板和电脑大屏上都能自然地查看文件、处理 Git、操作终端。

它不是要复刻完整桌面开发工具，而是把随时随地编程最需要的入口做轻：文件、Git、终端，以及围绕这些能力的状态反馈、主题和安全访问体验。

前端采用页面注册体系，除了工作区里的文件、Git、终端，也可以按需打开 AI 会话查看器、BlockTerm、进程监视器、端口管理器、遥控器、远程桌面、键盘测试等自定义工具页面。新建页面菜单中的条目可以在设置里控制显示或隐藏。

## 开发

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
```

## 检查

```bash
pnpm check
```
